關聯式數據庫基礎Relational Database Basics

選修A · Databases
STUDENT
關聯式數據庫把資料儲存在表格 (relation) 中。每一直行是欄位 (field / attribute),代表一種屬性;每一橫行是記錄 (record / tuple),代表一個個體。主鍵 (primary key) 是能唯一辨識每筆記錄的欄位 (如 StudentID),不可重複、不可留空。比起檔案式處理,數據庫減少重複 (redundancy)、便於共享及維持一致性。 A relational database stores data in tables (relations). Each column is a field / attribute (a property); each row is a record / tuple (one entity). The primary key is the field that uniquely identifies each record (e.g. StudentID) — no duplicates, never null. Versus file-based processing, a database cuts redundancy, eases sharing and keeps data consistent.
