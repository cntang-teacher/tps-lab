SQL 是查詢關聯式數據庫的語言。SELECT 選擇要顯示的欄位 (投影),FROM 指定表格,WHERE 按條件篩選記錄 (選擇),ORDER BY 排序結果。上方灰化的列代表被 WHERE 濾走的記錄。 SQL is the language for querying relational databases. SELECT picks the columns to show (projection), FROM names the table, WHERE filters records by a condition (selection), and ORDER BY sorts the result. Greyed rows above are those the WHERE clause filtered out.
