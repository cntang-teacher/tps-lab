ENROLMENT (子表child)
主鍵 (PK) 唯一辨識父表的每筆記錄。外鍵 (FK) 是子表中一個欄位,其值必須對應父表某個主鍵 —— 這樣就把兩個表關聯起來。參照完整性 (referential integrity) 要求每個外鍵都能找到對應主鍵;若指向不存在的值 (孤立記錄),數據庫會拒絕,以防資料不一致。 A primary key (PK) uniquely identifies each record in the parent table. A foreign key (FK) is a field in the child table whose value must match a PK in the parent — that\'s how the two tables are related. Referential integrity requires every FK to find a matching PK; a value pointing to nothing (an orphan record) is rejected to keep data consistent.
