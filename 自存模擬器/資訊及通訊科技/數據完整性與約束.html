約束檢查Constraint checks
完整性約束是數據庫自動執行的規則,確保資料有效:實體完整性 — 主鍵不可重複、不可留空;域約束 (domain) — 值須屬合法範圍／類型 (如 Age 11–25);格式 — 如 StudentID 須為 S + 三位數字;NOT NULL — 必填欄不可留空。任何一項不符,INSERT 都會被拒絕,以維持資料準確一致。 Integrity constraints are rules the database enforces automatically to keep data valid: entity integrity — the primary key must be unique and not null; domain — values must be of the right type/range (e.g. Age 11–25); format — e.g. StudentID must be S + three digits; NOT NULL — required fields can\'t be blank. If any check fails, the INSERT is rejected to keep data accurate and consistent.
