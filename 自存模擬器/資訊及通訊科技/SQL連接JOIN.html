選修A · JOIN
SELECT S.Name, E.Course
FROM STUDENT S INNER JOIN ENROLMENT E
ON S.StudentID = E.StudentID;

連接 (JOIN) 依據共同欄位 (這裡是 StudentID) 把多個表的資料合併。INNER JOIN 只保留兩邊都能配對的記錄;LEFT JOIN 保留左表全部,右邊沒配對就填 NULL。留意 S003 (Wong) 沒有選修記錄:INNER 會丟棄它,LEFT 則保留。 A JOIN combines rows from multiple tables on a common field (here StudentID). INNER JOIN keeps only records that match on both sides; LEFT JOIN keeps every left-table row, filling NULL where the right has no match. Note S003 (Wong) has no enrolment: INNER drops it, LEFT keeps it.
